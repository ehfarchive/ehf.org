# EHF Stage 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the accepted Astro spike into the approved static EHF public experience, with one manifest-controlled route for every included page and no source-host runtime dependency.

**Architecture:** `source-evidence/route-manifest.json` is the single versioned route contract. A typed loader validates it before Astro routes render any dynamic family. Typed content collections and local page data map only manifest records to template families; `src/lib/assets.ts` admits only hash-checked local assets while actual video, social, and donation destinations stay external. The existing four spike routes and shared Astro shell are extended in place rather than rebuilt.

**Tech Stack:** Astro 7 static output, TypeScript strict mode, Astro content collections with Zod, local CSS, Node scripts, Vitest, Playwright, and `@axe-core/playwright`.
